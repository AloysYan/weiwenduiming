# <center>底盘

## 一、走线：
- **功能**：实现稳定的线路连接，避免在使用单一杜邦线时可能出现的连接不稳定问题
- **设计思路**：从实现基本连接出发，逐步实现连接稳定与走线美观规范
- **开发历程**：
10/13 鉴于人手与时间不足，决定使用杜邦线进行连接，暂时不进行PCB板的绘制。
10/17 为进行线路连接，增加面包板
10/19 考虑到 1.面包板连接不太稳定 与 2.降压的需求，新增降压模块代替面包板
10/20 增加新的单片机连接模块（IO扩展板）代替面包板连接单片机

## 二、供电模块：
- **功能**：实现对不同元件的供电（可实现12V与5V供电）
- **设计思路**：从所需电压出发，控制不同模块供电电压
- **组成**：3节18650电池 + DC-DC 12V->5V 降压模块
- **开发历程**：
10/13 直接采用组委会建议的4节18650电池供电
10/18 经对其他元件的学习，认为采取3节电池会更加安全且在布线上更为方便，因此更换电池盒
10/20 增加DC-DC降压模块，为单片机供电

## 三、元件连接：
- **功能**：实现元件的稳固安装与连接
- **开发历程**：
  - 10/14 **换底盘前**：采用钉子进行连接，但遇到了钉孔不合适的情况，暂时重新设计底盘
  - 10/19 **换底盘后**：
    - **防短路设计**：由于新底盘为金属材质，一个单片机不幸殒命，因此采用绝缘胶带缠满底盘，并在元件下方垫海绵，防止元件下方锡焊口刺破胶布造成短路
    - **固件连接**：采用尼龙绳，使连接稳固、灵活、便于拆卸，不受钉孔约束

## 四、两辆车的不同设计：
- **二号车**：所有零件连接在底盘上，上层顶盘起到保护作用
- **一号车**：鉴于机械铲的特殊设计（见 ***4.弹丸携带*** ），我们将底盘作为弹丸装载模块使用，所有零件连接在顶盘上，通过上下均放置元件的排布方式节省了空间且便于接线
