# <center>底盘

## 一、走线：
- **功能**：实现稳定的线路连接，避免在使用单一杜邦线时可能出现的连接不稳定问题
- **设计思路**：从实现基本连接出发，逐步实现连接稳定与走线美观规范
- **开发历程**：
10/13 鉴于人手与时间不足，决定使用杜邦线进行连接，暂时不进行PCB板的绘制。
10/17 为进行线路连接，增加面包板
10/19 考虑到面包板连接不太稳定与降压的需求，新增降压模块代替面包板
10/20 增加新的单片机连接模块（IO扩展板）

## 二、供电模块：
- **功能**：实现对不同元件的供电（可实现12V与5V供电）
- **设计思路**：从所需电压出发，控制不同模块供电电压
- **组成**：3节18650电池 + DC-DC 12V->5V 降压模块
- **开发历程**：
10/13 直接采用组委会建议的4节18650电池供电
10/18 经对其他元件的学习，认为采取3节电池会更加安全且在布线上更为方便，因此更换电池盒
10/20 增加DC-DC降压模块
