# <center>PS2 手柄控制模块

## 参数获取：
- **功能**：获取返回参数以控制小车运动
- **设计历程**：通过解析 PS2 手柄的返回数据，我们获得了按钮的按下与松开状态，以及摇杆的精确位置。

***具体参数详见docs-知识笔记-电控-PS2***

## 底盘运动：
- **功能**：实现使用PS2遥控地盘运动
- **设计思路**：
  通过解析 PS2 手柄的返回数据，我们获得了按钮的按下与松开状态，以及摇杆的精确位置。
  - 方向控制：
    利用 PS2 摇杆的左右（LJoy_LR） 控制智能车的 平移，通过 PS2 摇杆的上下（LJoy_UD） 控制智能车的 前进与后退。
  - 速度控制
    摇杆的推动程度用于控制电机的速度，摇杆越远，电机的速度越高。

## 机械铲运动：
- **功能**：通过控制SG90舵机实现机械铲的转动
- **设计思路**：
  - 舵机控制：
    通过 PS2 按键（△、X） 控制舵机的正反转。按下三角形按键时，舵机正转，按下 X 键时舵机反转。
