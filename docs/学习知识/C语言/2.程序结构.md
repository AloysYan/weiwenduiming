# <center>程序结构

### 几种基本语句：
- if-else，for，while，do-while，switch-case，break，continue  

### 条件判断的运算符：
| 运算符 | 意义       |
| ------ | ---------- |
| ==     | 相等       |

| >      | 大于       |

### if-else：  
**基本语法**： 
```
if (条件表达式) {
    // 条件为真时执行的代码块
} else {
    // 条件为假时执行的代码块
}
```
**多条件（级联）语法**（类似py中的elif）：
```
if (条件1) {
    // 条件1为真时执行
} else if (条件2) {
    // 条件1为假，条件2为真时执行
} else if (条件3) {
    // 前面条件都为假，条件3为真时执行
} else {
    // 所有条件都为假时执行
}
```
- 与py的不同点：不能靠缩进判断else的意义

**嵌套语法**：
```
if (外层条件) {
    // 外层条件为真
    if (内层条件1) {
        // 内层条件1为真时执行
    } else {
        // 内层条件1为假时执行
    }
} else {
    // 外层条件为假时执行
}
```
- 这种情况下最好写的整洁一些，避免代码可读性太差

**不含括号版**：
```
if (条件表达式)
    单条语句1;  // 条件为真时执行
else
    单条语句2;  // 条件为假时执行
```
```
if (条件1)
    语句1;  // 条件1为真时执行
else if (条件2)
    语句2;  // 条件1假、条件2真时执行
else if (条件3)
    语句3;  // 前两个条件假、条件3真时执行
else
    语句4;  // 所有条件都假时执行
```
```
if (外层条件)
    if (内层条件)
        语句1;  // 外层和内层条件都为真
    else
        语句2;  // 外层真、内层假
else
    语句3;  // 外层条件为假
```
- 由于C语言中if-else顺序不严格由缩进影响，因此这样易出错，谨慎使用

### switch-case：
**基本语法**：
```
switch (表达式) {
    case 常量1:
        // 当表达式的值等于常量1时执行的代码
        语句1;
        break;  // 跳出switch语句
    case 常量2:
        // 当表达式的值等于常量2时执行的代码
        语句2;
        break;
    case 常量3:
        // 当表达式的值等于常量3时执行的代码
        语句3;
        break;
    // 可以有更多的case分支
    default:
        // 当表达式的值与所有case的常量都不匹配时执行的代码
        语句n;
        // default分支可以省略break，因为它是最后一个分支
}
```
#### switch-case和级联if-else的异同：
| **对比维度**         | **switch-case**                              | **级联if-else**                              |
|----------------------|----------------------------------------------|----------------------------------------------|
| **判断对象**         | 只能判断**整数类型**（int、char、枚举等）或可隐式转换为整数的表达式 | 可判断**任意类型**的条件（整数、浮点数、字符串比较等） |
| **判断逻辑**         | 基于**表达式的值与常量的精确匹配**            | 基于**条件表达式的真假**（可包含复杂逻辑）    |
| **执行效率**         | 通常更高，编译器可优化为跳转表（O(1)时间复杂度） | 按顺序判断，最坏情况需执行所有条件（O(n)时间复杂度） |
| **代码结构**         | 结构清晰，适合多分支且条件为离散常量的场景    | 结构相对冗长，适合条件复杂或范围判断的场景    |
| **穿透性**           | 存在穿透性（若省略`break`，会继续执行下一个case） | 无穿透性，一旦某个条件为真，后续条件不再判断  |
| **适用场景**         | 多分支且条件为固定常量（如菜单选择、状态码判断） | 条件为范围判断（如`x>10`）或复杂逻辑组合    |

### while：
**基本语法**：
```
while (循环条件) {
    // 循环体：条件为真时执行的代码
    语句1;
    语句2;
    // ...
    
    // 通常需要包含使循环条件趋于假的语句（避免无限循环）
    循环控制变量更新;
}
```
**简化形式（单语句循环体）**：
```
while (循环条件)
    单条语句;  // 循环体只有一条语句时可省略大括号
    循环控制变量更新;
```
### do-while：
**基本语法**：
```
do {
    // 循环体：至少执行一次的代码
    语句1;
    语句2;
    // ...
    
    // 通常包含使循环条件趋于假的语句（避免无限循环）
    循环控制变量更新;
} while (循环条件);  // 注意末尾的分号不能省略
```
**简化形式（单语句循环体）**：
```
do
    单条语句;  // 循环体只有一条语句时可省略大括号
while (循环条件);
```
- **do-while循环特别适合 "至少需要执行一次" 的场景，如用户输入验证、菜单交互等**

### for：
**基本语法**：
```
for (初始化表达式; 循环条件; 循环后操作) {
    // 循环体：条件为真时执行的代码
    语句1;
    语句2;
    // ...
}
```
- 说明：
  - 初始化表达式：循环开始前执行一次，通常用于初始化循环控制变量（如int i = 0）
  - 循环条件：每次循环前判断，结果为非 0（真）时执行循环体，为 0（假）时退出循环
  - 循环后操作：每次循环体执行完后执行，通常用于更新循环控制变量（如i++）
  - 循环体：可以是单条语句（此时可省略大括号）或多条语句组成的代码块
#### 常见变体模板：
**省略初始化表达式（变量已在外部定义）**:
```
int i;
for (i = 0; i < 10; i++) {
    // 循环体
}
```
**省略循环后操作（在循环体内更新变量）**:
```
for (int i = 0; i < 10; ) {
    // 循环体
    i++;  // 在循环体内更新控制变量
}
```
**无限循环（省略所有表达式）**:
```
for (;;) {
    // 循环体（需在内部用break控制退出）
    if (退出条件) {
        break;
    }
}
```
**多变量控制**:
```
for (int i = 0, j = 10; i < j; i++, j--) {
    // 循环体
}
```
**简化形式（单语句循环体）**:
```
for (int i = 0; i < 10; i++)
    单条语句;  // 循环体只有一条语句时可省略大括号
```
- **for循环将初始化、条件判断和变量更新集中在一处，结构紧凑，适合已知循环次数或有明确范围的场景（如遍历数组）。**
- **人话：for循环像一个计数循环：设定一个计数器，初始化它，然后在计数器到达某值之前，重复执行循环体，而每执行一轮循环，计数器值以一定步进进行调整，比如加1或者减1。**

### break：
- break用于立即终止当前所在的循环（for/while/do-while）或switch-case语句，跳出该结构并执行后续代码。

### continue：
- continue用于跳过当前循环体中剩余的语句，直接进入下一次循环的判断（不终止整个循环）。

#### break和continue的区别：
|关键字|作用|适用场景|
|---|---|---|
|**break**|终止整个循环或switch结构|需要提前结束循环的场景|
|**continue**|跳过本次循环剩余部分，进入下一次循环|需要跳过特定迭代的场景|

- 注意事项
    - **break**在循环中通常与if配合使用，用于满足特定条件时提前退出循环。
    - **continue**只影响当前循环的单次迭代，不会终止整个循环。
    - 两者都只作用于最内层的循环或switch结构（**嵌套结构中不影响外层**）。
