# <center>函数
### 定义：
**无参数、无返回值的函数**：
```
// 函数声明（通常放在文件开头或头文件中）
void 函数名(void);

// 函数定义
void 函数名(void) {
    // 函数体：实现具体功能的代码
    语句1;
    语句2;
    // ...
    // 无return语句（或可写return;）
}
```
**有参数、无返回值的函数**：
```
// 函数声明
void 函数名(参数类型1 参数名1, 参数类型2 参数名2, ...);

// 函数定义
void 函数名(参数类型1 参数名1, 参数类型2 参数名2, ...) {
    // 函数体：可以使用参数进行运算
    语句1;
    语句2;
    // ...
}
```
**无参数、有返回值的函数**：
```
// 函数声明（返回值类型为具体类型，如int、float等）
返回值类型 函数名(void);

// 函数定义
返回值类型 函数名(void) {
    // 函数体
    语句1;
    // ...
    return 返回值;  // 返回值类型需与声明的返回值类型一致
}
```
**有参数、有返回值的函数**：
```
// 函数声明
返回值类型 函数名(参数类型1 参数名1, 参数类型2 参数名2, ...);

// 函数定义
返回值类型 函数名(参数类型1 参数名1, 参数类型2 参数名2, ...) {
    // 函数体：使用参数进行运算
    语句1;
    // ...
    return 返回值;  // 返回计算结果
}
```
**说明**：
- 返回值类型：可以是 C 语言中的任意数据类型（如int、float、char等），void表示无返回值。
- 参数列表：多个参数之间用逗号分隔，void作为参数表示无参数（可省略，但建议显式写出以明确意图）。
- 函数声明与定义：声明只需函数名、返回值类型和参数列表（参数名可省略），以及**分号**。定义则需要实现完整的函数体。
- 函数调用：通过函数名(参数1, 参数2, ...)的形式调用，有返回值的函数可将结果赋值给变量。

### 函数的传递：
- C语言在调用函数时，永远只是把**值**传递给函数，而非变量本身（每一个变量都只在自己的函数空间中）

### 补充：变量的生存期和作用域：
- **生存期**：什么时候这个变量开始出现了，到什么时候它消亡了
- **作用域**：在（代码的）什么范围内可以访问这个变量（这个变量可以起作用）
- 对于本地变量（局部变量），这两个问题的答案是统一的：大括号内——**块**

### 本地（局部）变量的规则：
- 本地变量是定义在块内的
  - 它可以是定义在函数的块内
  - 也可以定义在语句的块内
  - 甚至可以随便拉一对大括号来定义变量
- 程序运行进入这个块之前，其中的变量不存在，离开这个块，其中的变量就消失了
- 块外面定义的变量在里面仍然有效
- 块里面定义了和外面同名的变量则掩盖了外面的
- 不能在一个块内定义同名的变量
- 本地变量不会被默认初始化
- 参数在进入函数的时候被初始化了
