## 1.两种硬件：贴片与插件  

### 1.1 贴片  
学长使用的贴片练习用**PCB板**[^1][链接][贴片练习板]  

- **焊接流程**
  1. 将**锡膏**[^2]涂在PCB板上
  2. 将焊接元件黏在锡膏上
  3. 将PCB板放在**加热台**[^3]上加热，或使用**热风枪**[^4]加热（无论哪种方式，都需要加热温度高于锡膏熔点）
  4. 完成焊接

### 1.2 插件  
学长使用的插件练习用**心形灯**[^5][链接][心形灯]

- **焊接流程**：
  1. 将元件按正负极指示插入心形板中
  2. 将元件多的一部分铁丝剪断
  3. 用**电烙铁**[^6]熔化**锡丝**[^7]，将剪断后的铁丝头与心形板焊接在一起（两焊接点不能相连！）
  4. 完成焊接

- **ps**：锡丝焊多了怎么办？
用电烙铁熔化锡点后，用**吸锡器**[^8]将锡吸回去，重新进行焊接  

## 2.电线的连接

### 2.1 使用绝缘端子连接  
- **连接流程**：
   1. 取两根**电线**[^9]，进行剥皮，在一根线上套上**绝缘端子**[^10]
       - 剥皮：使用**剥线钳**[^11]，按照对应的**AWG**尺寸（电线和钳子上都有标）握紧钳子，直接一拽
   2. 将两根裸露的线芯直接拧一块
   3. 将**绝缘端子**中的锡丝部分对准线芯连接处，用电烙铁？（我记不清了）熔化
   4. 完成连接
