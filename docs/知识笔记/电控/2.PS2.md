### 代码解读：

#### 一、PS2 与 STM32 通信方式概览

PS2 手柄使用一种类似 SPI 的串行通信协议（三线半双工）：
| 信号线   | STM32端定义       | 作用             |
| ----- | -------------- | -------------- |
| `DI`  | 数据输入 (STM32读取) | PS2 → STM32 数据 |
| `CMD` | 命令输出           | STM32 → PS2 命令 |
| `CLK` | 时钟信号           | 控制数据同步         |
| `CS`  | 片选信号           | 控制开始和结束        |
```
#define DI_PORT GPIOA
#define DI_PIN  GPIO_PIN_4
#define CMD_PIN GPIO_PIN_5
#define CS_PIN  GPIO_PIN_6
#define CLK_PIN GPIO_PIN_7
```
#### 二、数据读取核心流程

主要函数：
`void AX_PS2_ScanKey(JOYSTICK_TypeDef *JoystickStruct)`
执行逻辑：
1.拉低 CS，引导手柄进入通信模式
2.依次发送 9 个命令字节（PS2_cmnd）
3.同时接收 9 个响应字节（PS2_data）
4.释放 CS
5.解析出按钮状态和摇杆值

发送命令：
```
const uint8_t PS2_cmnd[9] = {0x01, 0x42, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00};
```
- 0x01：同步启动命令
- 0x42：请求手柄发送按键与摇杆状态
- 后续 0x00 是占位符，用于接收返回数据

#### 三、返回的数据结构（PS2_data[]）
| 字节索引 | 含义        | 备注                    |
| ---- | --------- | --------------------- |
| 0    | 0xFF      | 固定同步字节                |
| 1    | 模式字节      | 模式类型（数字/模拟）           |
| 2    | 固定0x5A    | 响应头                   |
| 3    | 按钮组1（低字节） | 十字键、START、SELECT 等    |
| 4    | 按钮组2（高字节） | ○ × □ △、L1/L2/R1/R2 等 |
| 5    | 右摇杆 X 轴   |                       |
| 6    | 右摇杆 Y 轴   |                       |
| 7    | 左摇杆 X 轴   |                       |
| 8    | 左摇杆 Y 轴   |                       |

#### 四、PS2按键对应的比特位

PS2按钮是 低电平有效：
- 按下按钮 → 位 = 0
- 松开按钮 → 位 = 1

在代码中：
```
JoystickStruct->btn1 = ~PS2_data[3];
JoystickStruct->btn2 = ~PS2_data[4];
```
使用了按位取反 ~，将“低有效”改为“高有效”，便于判断。

▶ **按钮组1 (PS2_data[3])**
| 位 | 掩码   | 按钮        | 说明（取反后） |
| - | ---- | --------- | ------- |
| 0 | 0x01 | Select    | 按下为 1   |
| 1 | 0x02 | L3（左摇杆按下） | 按下为 1   |
| 2 | 0x04 | R3（右摇杆按下） | 按下为 1   |
| 3 | 0x08 | Start     | 按下为 1   |
| 4 | 0x10 | ↑ 上方向键    | 按下为 1   |
| 5 | 0x20 | → 右方向键    | 按下为 1   |
| 6 | 0x40 | ↓ 下方向键    | 按下为 1   |
| 7 | 0x80 | ← 左方向键    | 按下为 1   |

示例：
```
PS2_data[3] = 0b11101111   // bit4=0 表示上键被按下
~PS2_data[3] = 0b00010000   // 转换后 bit4=1 表示按下
```

▶ **按钮组2 (PS2_data[4])**
| 位 | 掩码   | 按钮 | 说明（取反后） |
| - | ---- | -- | ------- |
| 0 | 0x01 | L2 | 按下为 1   |
| 1 | 0x02 | R2 | 按下为 1   |
| 2 | 0x04 | L1 | 按下为 1   |
| 3 | 0x08 | R1 | 按下为 1   |
| 4 | 0x10 | △  | 按下为 1   |
| 5 | 0x20 | ○  | 按下为 1   |
| 6 | 0x40 | ×  | 按下为 1   |
| 7 | 0x80 | □  | 按下为 1   |

示例：
```
PS2_data[4] = 0b11110111  // bit3=0 表示 R1 被按下
~PS2_data[4] = 0b00001000  // 转换后 bit3=1
```

#### 🎮 五、摇杆数据说明
| 成员        | 字节            | 含义    | 范围                |
| --------- | ------------- | ----- | ----------------- |
| `RJoy_LR` | `PS2_data[5]` | 右摇杆左右 | 0x00=最左 → 0xFF=最右 |
| `RJoy_UD` | `PS2_data[6]` | 右摇杆上下 | 0x00=上 → 0xFF=下   |
| `LJoy_LR` | `PS2_data[7]` | 左摇杆左右 | 0x00=最左 → 0xFF=最右 |
| `LJoy_UD` | `PS2_data[8]` | 左摇杆上下 | 0x00=上 → 0xFF=下   |

中心值通常在 0x7F ~ 0x80（127 ~ 128）

#### 🧩 七、举例说明
假设读取到：
```
PS2_data[3] = 0xBF  // 二进制：10111111
PS2_data[4] = 0xFF  // 二进制：11111111
```
分析：
- bit6（DOWN）= 0 → “下”方向键按下
因此：
```
btn1 = ~PS2_data[3] = 0x40;
```
判断：
```
if (ps2.btn1 & 0x40)
    MOTOR_Backward();  // 执行后退
```

#### ✅ 八、在控制中如何使用这些值

结合电机控制逻辑（L298N）：
```
if (ps2.btn1 & 0x10) MOTOR_Forward();   // ↑ 前进
else if (ps2.btn1 & 0x40) MOTOR_Backward(); // ↓ 后退
else if (ps2.btn1 & 0x80) MOTOR_Left();     // ← 左平移
else if (ps2.btn1 & 0x20) MOTOR_Right();    // → 右平移
else MOTOR_Stop();  // 无按键则停止
```

#### ✳️ 九、总结

- 按钮是低电平有效，所以需要取反后使用。
- 方向键主要在 btn1 中，功能键在 btn2 中。
- 摇杆是模拟输入，返回 0~255 范围的线性值。
- 在控制 L298N 时，只需要根据 btn1 或 btn2 的对应位来判断方向动作即可。
